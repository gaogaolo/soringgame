# 货架整理卡片 Sort 关卡编辑器 - 当前逻辑记忆

## 当前文件与用途

- 主编辑器：`fruitsort_level_editor.html`
- 单文件 HTML 编辑器，包含关卡配置、自动生成、可解性验证、试玩、JSON 导入导出。
- 该文件目前未纳入 Git；不要覆盖或清理同目录其他 APK 解析产物。

## 核心玩法

- 地图由 2 至 5 个列堆组成，每列的色组按 JSON 数组顺序从底部到顶部保存。
- 点击地图列时，取出顶部连续同色卡牌，并逐张尝试进入当前处于第一排的同色目标盒。
- 没有可承接的第一排同色目标盒时，卡牌进入暂存槽。
- 每个目标盒固定收集 6 张同色卡后消除；所有地图与暂存槽清空且目标盒完成即通关。
- 暂存槽固定为 13 格；达到 13 格即失败。
- 求解器以真实颜色判断是否存在通关路径，生成结果必须经过可解性验证。

## 固定边界与参数

- 地图列数：最少 2，最多 5。
- 收集盘列数：最少 2，最多 5。
- 颜色数：2 至 8。
- 目标盒总数：1 至 80。
- 暂存槽：固定 13，不可配置。
- 分割卡片数：最小值与最大值均为 1 至 6，且最小值不能大于最大值。
- 每个目标盒总共 6 张卡。若当前范围无法将 6 拆分为若干合法组，则阻止生成。例如 `4-5` 无合法拆分；`2-2` 只能生成 `2+2+2`。

## 分割、排列与可解生成

- `splitSix()` 基于当前最小/最大分割数，枚举所有总和为 6 的合法分割；优先使用与难度预设匹配的分割，若没有匹配项则从全部合法分割中选择。
- 随机候选路径与构造式保底路径都必须使用同一套合法分割，不允许保底路径产生越界的组数。
- 地图内相邻同色组会尽可能避免：若存在能使相邻颜色不同的列/交换方案，不应保留同色相邻；无法避免时才允许。
- 真实色组不可因相邻同色而在导出前合并；`MapColumns` 必须保留原始分组数量。求解器内部会按游戏点击逻辑压缩同色连续卡。
- 简单难度要求开局所有地图列都有可承接的顶层颜色；所有生成关卡还要求每个配置地图列非空。
- 自动生成先多次尝试随机候选，失败后尝试不同压力等级的构造式保底关卡；最终仅接受求解器确认可解且满足暂存峰值限制的关卡。

## 难度

- 五档：`easy`、`normal`、`medium`、`hard`、`hell`。
- 难度越高，越倾向让当前第一排目标盒暂时接不住的颜色靠前，并提高前段暂存压力。
- 难度配置影响目标盘排列、分割偏好、随机候选风险排序、开局可承接比例、构造式压力与求解器搜索预算。

## 隐藏机制

- 编辑器配置：`收集盘隐藏占比` 与 `地图列隐藏占比`，取值 0 至 100，默认 0。
- 比例以“可隐藏对象”作为分母，使用当前随机种子稳定抽样。
- 收集盘：每列第一排目标盒始终显示颜色；仅非第一排目标盒可以被标记 `hidden`。试玩中，未激活且隐藏的目标盒显示 `?` 卡背；成为第一排后显示真实颜色。
- 地图：每列顶层色组始终显示颜色；仅非顶层色组可以标记 `Hidden`。预览和试玩中隐藏色组显示 `?` 卡背，但保留 `xN` 数量。
- 隐藏只增加信息难度，不修改真实颜色、收集规则、生成规则或求解器可解性。
- 所有卡背不能有真实颜色 CSS 类、真实颜色文字或颜色悬浮提示，避免信息泄露。

## JSON 导出格式

最小可还原格式：

```json
{
  "Level": 1,
  "TargetColumns": [[0, 1], [2, 3]],
  "MapColumns": [[[0, 3], [1, 3]], [[2, 2], [3, 4]]]
}
```

- `Level`：正整数关卡编号。
- `TargetColumns`：外层区分收集盘列；内层按第一排到后排保存颜色编号。
- `MapColumns`：外层区分地图列；内层按底部到顶部保存色组。
- `[Color, Count]`：色组的真实颜色编号与连续卡牌数。
- 有隐藏对象时按需追加（无隐藏时不导出，保持 JSON 精简）：

```json
{
  "TargetHidden": [[0, 1]],
  "MapHidden": [[1, 0]]
}
```

- `TargetHidden`：`[收集盘列索引, 目标盒索引]`，索引从 0 开始。
- `MapHidden`：`[地图列索引, 色组索引]`，地图色组索引按底部到顶部计算。
- 导入 JSON 时，`TargetColumns` 与 `MapColumns` 都必须为 2 至 5 列；隐藏坐标必须存在、无重复且不越界。缺少隐藏字段则全部可见。

## 已验证事项

- 分割范围 `2-5`：所有实际导出色组数量均在范围内且关卡通过可解验证。
- 分割范围 `2-2`：仅生成 2 张色组。
- 分割范围 `4-5`：阻止生成并给出无法拆分总数 6 的提示。
- 简单难度、均衡、3 地图列：生成 3 个非空列并通过可解验证。
- 隐藏比例 100%：覆盖全部可隐藏目标盒与地图色组；卡背不泄露颜色；导出再导入后隐藏坐标完全一致。
- 列数：UI、运行时夹紧和导入校验都已验证为 2 至 5；输入 1 会回正为 2，单列 JSON 会被拒绝。
